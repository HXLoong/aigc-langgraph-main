# otc-agent 业务方使用培训

> **编写者**：图灵科技
> **目标读者**：客户业务方（销售 / 交易员 / 业务支持）使用企微 otc-agent 机器人的同事
> **预期时长**：30 分钟培训会 + 10 分钟答疑
> **目的**：让你 30 分钟后能：
>
> 1. 知道在企微群里向 AI 提问要怎么说，AI 才能听懂
> 2. 知道哪些是 AI 真的不会的情况（不是 bug）
> 3. 知道遇到错误时该怎么反馈、找谁

---

## 1. otc-agent 是什么

简单说——**它是一个企微群里的助手机器人**，专门处理场外衍生品的常见操作：

- 期权询价 / 下单 / 修改 / 撤单 / 平仓
- 互换询价 / 下单 / 撤单 / 查询
- 标的代码查询

它是从原来的 Dify 工作流升级过来的。从你（业务方）的角度，**用法基本一样**——在企微群 @它 然后说事情。

> 内部技术升级：原 Dify 工作流 → 新 LangGraph 引擎 + 升级的标的识别 + 更稳定的参数提取。

## 2. 怎么向 AI 提问最有效

### 2.1 一句话说清"产品 + 操作 + 标的"

| 你说 | AI 理解 |
|---|---|
| "600519.SH 询价 3 个月平值看涨" | ✅ 期权询价：标的 600519.SH，期限 3 个月，平值，看涨 |
| "贵州茅台 询价" | ✅ 期权询价：贵州茅台（标的简称→代码）|
| "做个互换" | ❌ 信息不够——什么标的？多少本金？多长期限？AI 会反问 |
| "撤单" | ❌ 撤哪一单？AI 不知道你指的是哪条订单 |

**建议**：每条消息至少包含**产品** + **操作** + **标的**这三个要素，越具体越好。

### 2.2 用"引用消息"功能补充上下文

企微的"引用回复"AI 能看到。**强烈推荐**用这个功能补充上下文：

| 场景 | 推荐做法 |
|---|---|
| 撤一条订单 | 引用之前的"下单成功"消息，再发"撤单"——AI 自动知道撤哪一单 |
| 修改之前询价 | 引用之前的"询价详情"消息，再发"改成 6 个月" |
| 确认操作 | 引用之前的"询价/下单/撤单详情"消息，再发"确认" |

> 不引用就发"撤单 / 确认"，AI 不知道你想撤什么、确认什么——会反问或猜错。

### 2.3 标的怎么写都行

AI 能识别多种写法：

| 你写 | AI 都能识别 |
|---|---|
| `600519.SH` | ✅ |
| `贵州茅台` | ✅ |
| `茅台` | ✅（简称白名单） |
| `0700.HK` | ✅（4 位港股自动补 0）|
| `腾讯` | ✅ |
| `50ETF` / `沪深300` / `创业板指` | ✅ ETF + 指数也能 |

但**这些情况** AI 识别有难度：

- 错别字：`贵州毛台`（应该是茅台）→ 0 命中，AI 会请你换种说法
- 极简缩写：`茅` 单字 → 可能识别失败
- 网络昵称：`宁王`（宁德时代）→ 可能不在词库

如果遇到，**换标准名称或代码**即可。

## 3. 4 类场景实例（核心）

### 3.1 期权询价

**示例 1：完整一句话**
- 你：`@otc-agent 600519.SH 询价 3 个月平值看涨`
- AI：会给出询价详情卡片（标的 / 期权类型 / 期限 / 执行价 / 费率），让你确认参数后补充【交易对手】【名义本金】【建仓指令】

**示例 2：分步对话**
- 你：`@otc-agent 贵州茅台 询价`
- AI：会反问"请明确期限、期权类型、执行价"或给出默认询价并请你确认

**示例 3：多标的批量**
- 你：`@otc-agent 600519 000858 询价`
- AI：会同时给两支标的的询价详情

### 3.2 期权下单 / 修改 / 撤单

**下单**：
- 你引用一条"询价详情"消息 + 发：`确认下单，对手方 XX，本金 1000 万`
- AI：会下单到后端系统，回传订单号

**修改**：
- 你引用"询价详情"+ 发：`改成 6 个月`
- AI：修改参数后回新的询价详情

**撤单**：
- 你引用"下单成功"消息 + 发：`撤单`
- AI：撤掉该订单，回传撤单成功

### 3.3 期权平仓

**全平**：
- 你引用"持仓查询"消息 + 发：`全部平仓`
- AI：列出待平仓订单，等你回复"确认平仓"

**部分平仓**：
- 你：`@otc-agent 平仓 600519 一半`
- AI：列出 600519 的持仓，平 50% 等你确认

### 3.4 互换询价 / 下单

**询价**：
- 你：`@otc-agent 互换询价 600519 3 个月 收益互换`
- AI：互换询价详情（标的 / 期限 / 互换类型）

**下单**：
- 引用询价详情 + 发：`确认下单`
- AI：下单到后端，回传订单号

### 3.5 互换查询 / 撤单

**查持仓**：
- 你：`@otc-agent 我的互换持仓`
- AI：列出当前互换订单

**撤单**：
- 引用"下单成功"+ 发：`撤单`

## 4. AI 哪些情况会"说听不懂"

### 4.1 真的听不懂（请换种说法）

| AI 说什么 | 你做什么 |
|---|---|
| "抱歉，无法识别「XXX」中的标的" | 用标准代码（如 `600519.SH`）或完整名称（如 `贵州茅台`）|
| "我没完全理解你的意思，能换种说法重新告诉我吗？" | 把"产品 + 操作 + 标的"都说清楚 |
| "请明确期限/期权类型/执行价" | 补充缺失的参数 |
| "以下标的均可能匹配，请确认选择哪个" | 从 AI 列出的候选中选 |

这些都是**AI 正常的引导行为**，不是 bug——AI 不确定时宁可问你，也不会瞎猜。

### 4.2 已知局限

| 场景 | 现状 | 应对 |
|---|---|---|
| 极简缩写"撤单"无引用 | 不知道撤哪单 | 引用对应订单消息 |
| 错别字（毛台 vs 茅台）| 后端证券工具可能识别不到 | 用标准名称或代码 |
| 网络昵称（宁王 / 茅 单字）| 后端证券工具可能识别不到 | 用标准名称或代码 |
| Excel 文件批量下单 | 仅收益互换下单支持 | 期权请用文字描述 |
| 图片识别截图 | 仅收益互换下单支持，识别结果需核对订单卡 | 期权请用文字描述 |

### 4.3 多轮对话上下文

- AI **记得**同一企微群内你最近几次的对话（会话记忆）
- **同一会话内**可以续接（"再加 100 万本金"）
- **跨会话**记忆有限（不会记你昨天聊的内容）

## 5. 严重错例的标准（哪些算 bug 要反馈）

为了让大家反馈问题不至于太主观，**以下情况算严重错例**（必须反馈）：

| 严重错例 | 例子 |
|---|---|
| **标的错** | 你说"600519 询价"，AI 却把订单提交给 000858 |
| **参数错** | 你说"3 个月期限"，AI 提交的订单写 6 个月 |
| **意图大类错** | 你说"询价"，AI 当成"下单"直接提交了 |
| **系统完全不工作** | AI 一直不回复、或回复"内部错误" |

以下情况**不算严重错例**（属于正常）：

- AI 反问参数（信息不全时正常引导）
- AI 用"抱歉，无法识别"兜底（标的真不在词库）
- AI 给出消歧候选让你选（多个标的同名时正常）
- 个别极少出现的偏差（< 1% 的概率，可累积反馈但不紧急）

## 6. 遇到问题怎么反馈

### 6.1 反馈渠道

| 反馈类型 | 找谁 | 通过什么 |
|---|---|---|
| **严重错例**（§5 表格中） | 业务方负责人（sign-off 人） | 邮件 / 企微群直接 @ |
| 一般偏差 | PM | 周报 / 企微群 |
| 使用问题 / 培训需求 | Tony（项目负责人） | 企微 |
| 紧急情况（AI 大面积不工作） | 客户企微管理员 → 临时切回 Dify | 1 分钟内可切 |

> 联系人具体名字和方式见培训会现场发的"联系人卡片"或问 PM。

### 6.2 反馈时请提供

| 字段 | 例子 |
|---|---|
| 时间 | 2026-05-13 上午 10:30 |
| 群名 | 企微群"XX 销售互动群" |
| 你的原话 | "600519 询价 3 个月" |
| AI 的回复 | （截图最直观）|
| 你期望的回复 | "期权询价：标的 600519.SH..."|

> 时间和群名是关键——技术团队靠这两个字段在监控里查到对应记录。

### 6.3 紧急回切（AI 大面积不工作时）

如果短时间内多个群同时出现 AI 不回复或回复错乱，企微管理员可以**1 分钟内**把流量切回原来的 Dify 系统。具体操作技术团队已经培训过企微管理员，你只需要：

1. 在群里通报"AI 系统异常，已切回备用系统"
2. 通知业务方负责人 + Tony
3. 等技术团队修复后再切回

## 8. 常见问题 FAQ

**Q：以前用 Dify 的下单流程，现在还能用吗？**

A：能。从你的角度操作没变。AI 升级后**对参数提取更准、对标的识别更稳定**。

**Q：我以前发的"撤单"AI 能猜到，现在为什么要引用？**

A：以前 Dify 偶尔猜对，但也经常猜错。新版 AI 不猜——你引用了就 100% 准确，不引用它就反问，避免错单。

**Q：AI 提交给后端的数据和我看到的回复一致吗？**

A：一致。AI 会把"询价详情"卡片上每个字段都原样传给后端系统。如果你看到询价详情没问题就放心确认。

**Q：AI 错了一次，下次还会错吗？**

A：每条消息独立处理。AI 不会"学坏"——但同样的问题输入，AI 大概率会同样回答。所以严重错例反馈给技术团队后会**修复一次终身有效**。

**Q：周末 / 节假日 AI 工作吗？**

A：工作，7×24 小时。但**严重错例的修复**通常在工作日处理。
