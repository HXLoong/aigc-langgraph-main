## 4. 复检脚本

下次审计可跑这 3 条命令快速复检：

```bash
cd /path/to/aigc-langgraph

# 4.1 ADR 互引完整性
grep -hoE "ADR ?0[0-9]{3}" docs/adr/00*.md | grep -oE "0[0-9]{3}" | sort -u | while read -r ref; do
    if ! ls docs/adr/${ref}-*.md >/dev/null 2>&1; then
        echo "❌ 虚悬: ADR ${ref}"
    fi
done

# 4.2 ADR 引用的代码路径有效性（Python 一行）
# 注意：跳过 ~~strikethrough~~ 段（已被 Status update 标 deprecated 的历史原文）
python3 -c "
import re
from pathlib import Path
adr_files = sorted(Path('docs/adr').glob('00*.md'))
rx = re.compile(r'\`((?:app|scripts|harness|tests)/[a-zA-Z0-9_./]+\.(?:py|md|yaml|yml|json))\`')
strike_rx = re.compile(r'~~.*?~~', re.S)  # 跳过删除线段
for adr in adr_files:
    text = strike_rx.sub('', adr.read_text(encoding='utf-8'))
    for m in rx.finditer(text):
        if not Path(m.group(1)).exists():
            print(f'{adr.name}: ❌ {m.group(1)}')
"

# 4.3 引用热度（看孤儿 ADR）
grep -rohE "ADR ?0[0-9]{3}" --include="*.py" --include="*.md" \
    docs/ app/ scripts/ harness/ tests/ 2>/dev/null \
    | grep -oE "0[0-9]{3}" | sort | uniq -c | sort -rn
```

建议：每新增 5 个 ADR 跑一次；F4 切流前 + M4 退出门前必跑。
