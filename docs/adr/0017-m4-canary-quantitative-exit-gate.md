# ADR 0017 · 金丝雀切流退出门量化指标（历史存根）

- 状态：**已被 [ADR 0030](./0030-goal-restatement-native-langgraph-dataset-eval-harness.md) 取代**（2026-09-22；指标并入 0030 D3"上线观察"层）
- 日期：2026-05-12
- 作者：图灵科技 + Tony

## 原决策

为"切流 100% 后能否下线 Dify"定义量化退出门：5xx 率 < 0.1%、cascade 失败率 < 1%、P95 ≤ 基线 × 1.5（均为 7 天）、业务方严重错例 ≤ 5 次 / 7 天，外加业务方书面同意。

取值理由：服务崩溃应近似为零；1% 是"用户能感知但不至于认为 AI 坏了"的临界；聊天体验由尾部延迟决定；错例阈值不取 0 以免永远无法签字。

## 为何被取代

Dify 已于 2026-09-17 退出上游，"下线 Dify"不再是待判定事项。指标本身仍有效，已作为上线观察层写入 ADR 0030 D3；原基线数值（Qwen 口径）作废，待当前模型重测。

## 仍有效的事实

- 5xx 与 cascade 率来自 `/metrics`，分母为总请求数；P95 取 `/v1/workflows/run` 端到端延迟。
- 故障期间的定级阈值见 [ADR 0019](./0019-incident-severity-thresholds.md)，与退出门方向相反、刻意拉开。
