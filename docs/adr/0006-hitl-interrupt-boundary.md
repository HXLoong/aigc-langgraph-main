# ADR 0006 · Human-in-the-Loop 边界：写操作 + 资金风险才需二次确认

- 状态：interrupt 机制已被 [ADR 0021](./0021-text-confirm-replaces-interrupt.md) 取代；本文的"写 + 资金双轴"风险规则继续有效
- 日期：2026-05-10
- 作者：图灵科技 + Tony

## 决策（仍有效）

用两条轴判断一个意图是否必须经过客户二次确认：**是否产生不可逆的后端写操作**、**是否涉及资金或合约履行**。

| 类型 | 示例 | 需要二次确认 |
|---|---|---|
| 纯查询 | 持仓、订单状态、报价 | 否 |
| 写操作但低风险 | 修改无金额影响的字段 | 否 |
| 写操作 + 资金 / 合约 | 下单、撤单、改单、平仓 | **是** |
| 已确认的二阶段意图 | 确认下单 / 确认撤单 / 确认平仓 | 否（本身就是确认） |

新增产品（如结构化产品）时，必须先按上表标注每个意图。

## 被取代部分

原方案用 LangGraph `interrupt_before` 拦截写节点、等待按钮回调恢复。该机制从未落地；2026-08-27 起确认方式统一为**文本二阶段确认**（客户回复"确认 + 订单引用"触发写操作），见 [ADR 0021](./0021-text-confirm-replaces-interrupt.md)。

## 备选方案

全拦（摩擦过大）/ 不拦（下错单代价不可接受）/ **写 + 资金双轴（已选）**。
