# Triage 标签

各技能以五个标准 triage 角色来描述 issue 状态。本文件将这些角色映射到本仓库实际使用的标签字符串。

| 技能中的角色标签       | 本仓库使用的标签    | 含义                           |
| ---------------------- | ------------------- | ------------------------------ |
| `needs-triage`         | `needs-triage`      | 维护者需要评估此 issue         |
| `needs-info`           | `needs-info`        | 等待提问者补充信息             |
| `ready-for-agent`      | `ready-for-agent`   | 已完整描述，AI 可无人值守接手  |
| `ready-for-human`      | `ready-for-human`   | 需要人工实现                   |
| `wontfix`              | `wontfix`           | 不会处理                       |

当技能提到某个角色（如"打上 AFK-ready triage 标签"）时，使用本表右列对应的标签字符串。

如需修改标签名称，编辑右列即可。
