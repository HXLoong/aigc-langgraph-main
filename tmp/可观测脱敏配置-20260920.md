# 可观测脱敏配置

按用户 2026-09-20 的要求，项目的字段脱敏改为显式开启，默认关闭，不因 development / staging / production 自动启用。

当前 `.env`、`.env.example` 和 `.env.customer.template` 已同步：

```dotenv
TELEMETRY_MASKING_ENABLED=false
TELEMETRY_MASKING_FIELDS=password,secret,api_key,token,authorization
```

## 生效范围

- 当前服务 Langfuse 客户端的 `mask_sensitive` 回调：处理传入的 Input、Output、Metadata 等结构化数据。
- 项目结构化日志的 `redact_log` 使用同一开关和列表。
- 不修改业务 State、Java 请求、用户回复或数据库审计数据。
- 不改动 Trace ID、Session ID 等关联标识；SDK 独立设置的顶层属性不等同于 Input/Output 内同名字段，此配置不是任意 OpenTelemetry 属性的全局过滤器。

## 字段匹配规则

1. `false`：直接返回原数据，字段列表不生效。
2. `true`：仅把列表中指定字段的值替换为 `[redacted]`。
3. 字段列表用英文逗号分隔，允许空白和重复；空列表不隐藏任何字段。
4. 字段名忽略大小写、下划线和连字符，例如 `user_id` 匹配 `userId`、`USER-ID`。
5. 递归处理字典、列表和 Pydantic 模型；选中父字段如 `sources` 时，该字段的整个值被隐藏。
6. 扁平审计键如 `swap/place_order.orderList.0.placeOrderShortname` 按最后一段字段名匹配。这是字段名规则，不是完整路径或通配符规则。
7. `content` 还控制 LangChain 的 `(role, content)` 消息形式；不配置它就不会整段隐藏提示词。
8. `value` 不再被无条件隐藏。若需要隐藏字段记录的所有 value，显式配置 `value`；也可以配置 `field_records` 隐藏整组字段记录。
9. 不再自动扫描手机号、邮箱、Bearer、连接串或自由文本，也不解析字符串内部的 JSON；例如日志 `event` 中出现文字 `token=...`，不会因为配置了 `token` 就被改写。

## 示例

只隐藏账号标识及凭据字段，保留交易原文、模型消息和结果：

```dotenv
TELEMETRY_MASKING_ENABLED=true
TELEMETRY_MASKING_FIELDS=password,secret,api_key,token,authorization,user_id,room_id,guid
```

另外隐藏原文、引用、模型消息和证据：

```dotenv
TELEMETRY_MASKING_ENABLED=true
TELEMETRY_MASKING_FIELDS=password,secret,api_key,token,authorization,raw_text,message_content,quote_content,content,evidence,sources
```

修改配置后重启实际运行的 LangGraph 服务：Settings 是进程内缓存，不能依赖 `.env` 自动热加载。旧 Trace 已经保存为 `[redacted]` 的字段不会恢复；后续新记录按新配置处理。

实现位置：`app/config.py`、`app/observability/privacy.py`。Langfuse 保留原有 mask 回调接线，由回调内部根据配置决定是否处理；无需手动删除 `mask=`。

本次仅做脱敏配置及相关代码调整，没有升级 SDK、重启用户服务或执行交易回归。
